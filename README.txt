Jo & Co Cards – PWA

Ins GitHub-Repository hochladen:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> / (root).

Danach die GitHub-Pages-Adresse auf dem Smartphone in Chrome öffnen.
Im Browser-Menü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ auswählen.

Die hochgeladene Jo-&-Co-Card-Grafik wird als PWA-App-Symbol verwendet.
